这篇给你一套可直接复用的收藏流程：

- 入口统一
- 自动分类
- 低资源消耗
- 长期可执行

## 1）触发规则

当你发送：**“收藏 + 网址”**，就执行收藏。

目标页面固定：

- <https://www.notion.so/***（已脱敏）>

## 2）分表路由规则

同一页面下按类型写入：

- OpenClaw 相关（链接或简介含 openclaw，或手动指定）→ **OpenClaw收藏表**
- GitHub 仓库 → **GitHub收藏表**
- 文章/博客/文档 → **文章收藏表**
- 视频站点 → **视频收藏表**
- 在线工具/产品页 → **工具收藏表**
- 社媒帖子 → **社媒收藏表**
- 无法识别 → **默认收藏表**

## 3）写入策略（关键）

每次都：

- **直接追加一行**
- **不查重，不读取整表**

这样做的好处：更快、更省资源、更稳定。

## 4）统一字段

所有表统一 4 列：

- 名称
- 链接
- 中文简介
- 收藏时间（**UTC+8**）

## 5）中文简介生成

目标：一句话说明链接内容。

顺序：

1. 先用轻量信息（title/meta/最小 API）
2. 不够再轻量补读（正文前几段或 README 前几段）

## 6）完成反馈

收藏成功后只回复：

- **完成**

## 可直接抄用的模板

> 触发：收藏 + 网址  
> 动作：按类型路由到对应 Notion 分表，直接追加，不查重  
> 字段：名称/链接/中文简介/收藏时间（UTC+8）  
> 反馈：完成
